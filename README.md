\# Waniqo Store



Waniqo Store is a modern full-stack e-commerce platform built with React, Tailwind CSS, Django REST Framework and PostgreSQL.



\## Tech Stack



\### Frontend

\- React

\- Vite

\- Tailwind CSS



\### Backend

\- Python

\- Django

\- Django REST Framework



\### Database

\- PostgreSQL



\### Payment

\- Razorpay



\## Features



\- Customer authentication

\- Separate admin authentication

\- Product management

\- Categories

\- Shopping cart

\- Wishlist

\- Checkout

\- Orders

\- Online payments

\- Product reviews

\- Admin dashboard

\- Sales analytics
